# No XAML Required: Native Windows Apps in Pure C#

**Speaker(s):** Alexandre Zollinger Chohfi

## Summary

Presents Microsoft.UI.Reactor, an experimental MVU framework that builds WinUI 3 apps entirely in C# (even a single file run with dotnet run), with hooks-based state and Roslyn analyzers, and candid discussion of its trade-offs versus XAML/MVVM.
