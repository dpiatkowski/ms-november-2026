# Building great Windows apps with WinUI and agents

**Speaker(s):** Morten Nielsen, Niels Laute

## Summary

Morten Nielsen and Niels Laute cover where WinUI is today and how to build WinUI apps with coding agents. WinUI is now open source with GitHub as the source of truth, ships an experimental and a stable release every month, and is meant to feel like modern .NET (dotnet new, dotnet run, the editor you like).

## Key points

- What's new: new controls (Chart, TableView, Ink), performance work (faster default styles, fewer allocations, boxing-free bindings), better crash dumps, WinUI analyzers, new windowing APIs, GameInput support, ThemeResources in code, and refreshed pickers/title bar.
- Developer experience: the WinApp CLI (create, build, run, debug, inspect and package from the command line), a WinApp VS Code extension with integrated debugging and UI inspection, and Visual Studio improvements.
- Agent-readiness: the WinApp CLI 'gives agents hands' (run the app, see the UI, inspect, debug, package) and a WinUI plugin with the winui-dev agent and WinUI skills 'gives agents Windows knowledge'; install via dotnet new templates, winget (Microsoft.winappcli) and a copilot plugin, followed by a demo.
- Related sessions: CsWinRT 3.0 (BRK024), Reactor/no-XAML apps (BRK027).
