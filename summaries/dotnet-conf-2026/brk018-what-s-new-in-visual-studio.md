# What's new in Visual Studio

**Speaker(s):** Jason Chlus

## Summary

Jason Chlus' keynote-follow-up slides are essentially a checklist of the Visual Studio features shown that day; text on the deck is limited to feature names (some marked as off by default and found by searching Tools > Options).

## Key points

- Navigate and edit: File System View, drag files and images into chat and Markdown, new Markdown file, HTML-to-CSS navigation, CSS color preview.
- Copilot: customizable chat defaults and a new Copilot Chat experience; code review: local review, multi-file summary diff, address comments in chat, comment filters, change groups.
- Build and test: stop solution build after the first project fails (off by default), Test Explorer improvements (assertion string comparison, open test log, last run time).
- Personalization and UI: tab improvements (keyboard moves, tool-window tab sizing, close tabs to the right, faster drag), Fonts and Colors and Keyboard Shortcuts UIs, colorized output (off by default), zoom reset, Hot Exit (reopen unsaved documents).
