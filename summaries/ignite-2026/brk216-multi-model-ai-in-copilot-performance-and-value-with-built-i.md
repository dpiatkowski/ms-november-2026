# Multi-model AI in Copilot: Performance and value with built-in trust

**Speaker(s):** Peter Bergen, Nagu Rangan, Natan Szymczyk

## Summary

The session explains how Copilot offers multiple models (Anthropic, OpenAI and others) in one governed experience, with Auto selecting the model and effort per task so users need not choose mode, model, effort and cost themselves. Auto is shown routing a customer-renewal slide deck across a lead model and sub-task models for files, research, images and slides.

The commercial model separates everyday AI under a per-user subscription from agentic, usage-billed work for power users. A GigaOm and Microsoft TCO report (October 2026) compares modeled monthly costs for Copilot, Claude and ChatGPT for an everyday user (100 tasks) and an advanced user (140 tasks including 20 agentic workflows); the slides note these are modeled estimates, not invoices or guaranteed savings. Governance is positioned through Agent 365 controls.
