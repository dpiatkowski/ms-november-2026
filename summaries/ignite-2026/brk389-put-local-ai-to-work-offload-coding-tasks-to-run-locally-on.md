# Put Local AI to Work: Offload Coding Tasks to run locally on Windows

**Speaker(s):** Neil Hinnant, Lei Xu

## Summary

The session shows offloading coding work to run locally on Windows as part of hybrid inferencing. Local and cloud are positioned as complementary: local for routine and privacy-sensitive work, cloud frontier models for hard reasoning, and "token factories" (shared local inference servers on Windows) for dedicated capacity, with Microsoft Foundry for elastic compute.

Device inference becomes part of the GitHub Copilot stack (CLI, app, VS Code). Copilot Fusion routes tasks using patterns such as single, cascade (a first-pass model with a judge that escalates only when needed) and critique, or users can define controlled delegation with custom agents and skills or run fully local. Governance and agent identity for local agents are covered through the Windows MXC platform.
