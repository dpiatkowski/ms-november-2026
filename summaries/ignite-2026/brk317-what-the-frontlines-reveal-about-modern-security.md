# What the Frontlines Reveal About Modern Security

**Speaker(s):** Troy Lainhoff, Vlad Suarez

## Summary

Microsoft Defender Experts researchers share frontline observations: attackers exploit trusted identities and legitimate activity, one incident can expose wider gaps in response readiness, and AI accelerates attacks. The three takeaways are that threat intelligence must be contextual and actionable, resilience is built before an incident, and defense must keep pace with machines while keeping humans in control.

A ClickFix case study reconstructs how a fake "verify you're human" prompt leads a user to paste and run a command, with 28 scripts executed in a chain and C2 beaconing found through network hunting, then turns it into shared intelligence and detections. A three-step exercise (identify the assumption, test an alternative path, own the next step) helps turn intelligence into action, and the session describes Defender Experts Threat Intelligence (outside-in) and 24/7 hunting (inside-out).
