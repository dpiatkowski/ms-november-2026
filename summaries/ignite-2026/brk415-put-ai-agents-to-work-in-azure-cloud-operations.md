# Put AI agents to work in Azure cloud operations

**Speaker(s):** Brendan Burns, Ruhiyyih Mahalati

## Summary

The session shows agentic operations in Azure: agents embedded in workflows to reduce toil, context-aware agents that improve over time, and built-in guardrails, across cloud, hybrid and edge. Ecolab reports faster issue detection with Azure Monitor health models, faster root cause analysis with Azure SRE Agent, 30 minutes saved per alert with Azure Copilot Observability Agent and 3-4 hours reclaimed per incident (customer-reported).

Architecture: Azure Resource Graph (live inventory), Azure Resource Manager (RBAC and policy enforced on every write) and the ARM MCP Server (public preview, now able to create, manage and update resources with previews of proposed changes). Four demos cover build (deploy a test environment from any coding agent), optimize (Azure Copilot with native FinOps skills finds a cost spike), recover (SRE Agent investigates incidents) and govern (agent identity, access and policy with Azure Policy).
