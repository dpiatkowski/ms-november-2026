# What’s new and what’s next for Windows Server

**Speaker(s):** Elden Christensen, Neil Hinnant

## Summary

The session sets the strategic direction for Windows Server and previews Windows Server 2028 (public preview): multi-layered security hardened by default, an advanced AI platform for enterprise inference on cutting-edge silicon, and adaptive cloud capabilities with Azure Arc and Intune. New themes are hybrid intelligence (running AI inference alongside applications and data), a higher access and security bar for the OS, VMs, identity and encrypted communications, faster infrastructure performance, and management at scale.

The slides frame local, hybrid and cloud AI choices (local only, hybrid with routing, cloud only) and "token factories" for shared local inference, and outline the next decade around server security, Azure everywhere, hybrid intelligence infrastructure and modern licensing.
