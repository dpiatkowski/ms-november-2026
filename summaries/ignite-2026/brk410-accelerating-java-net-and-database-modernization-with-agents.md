# Accelerating Java, .NET, and database modernization with agents

**Speaker(s):** Nish Anil, Elizabeth Barnitt

## Summary

The session announces Azure Catalyst as one connected experience across infrastructure, apps and data for agent-led modernization, built on the argument that modernization is now an AI imperative (Forrester surveys cited). It centers on GitHub Copilot modernization: a modernization agent to scale assessments and upgrades, database modernization aligned with the application journey (public preview), rulebooks (generally available) that apply an organization's standards in Markdown to every execution plan, and custom skills.

It supports .NET, Java, mainframe, VMware, Oracle, Sybase and SQL, in VS Code, Visual Studio, IntelliJ, CLI and GitHub.
