# Secure and manage AI workloads at enterprise scale with AI Gateway

**Speaker(s):** Mike Budzynski, Facundo Santiago, Raghu Balam

## Summary

The session announces Azure AI Gateway as generally available: a fully managed layer (16 Azure regions, Private Link inbound and virtual network integration outbound) that governs access to models, MCP tools and agents. Capabilities include Entra token validation with Azure RBAC, model routing (aliases, session affinity, Foundry model router selection, weights, priority and failover, preview), consumption policies (cost, token and request rate limits), safety policies (IP filter, content safety, tool threat protection), agent hooks and MCP tool publishing with allowlists.

Agent 365 can enforce tool restrictions on gateway-routed requests, and a coding-agent plugin helps discover gateway assets and generate agent code. Komatsu describes scaling AI across the company with one shared foundation for model connection, identity and credentials, and consumption control.
