# Where agents meet analytics: Build with SQL Database in Fabric

**Speaker(s):** Anna Hoffman, Lumir Hlavac

## Summary

The session covers building with SQL database in Fabric, which runs the familiar SQL engine inside Microsoft Fabric with provisioning, Copilot, T-SQL support and unified billing, and mirrors near real time to OneLake (open Delta) for analytics. Fabric Apps (also called Rayfin) are now generally available as a managed backend where an agent authors the app and deploys it with database, functions and auth.

Shipped in 2026: creating Fabric apps and SQL databases from SSMS, collation choice, DiskANN vector indexes and vector search, fuzzy string matching, full-text indexing and regex on large text (generally available), plus preview items such as SQL database skills for coding agents, Copilot in Database Hub, database agents for performance and workspace-level Private Link. Mirroring can replicate Azure SQL Database, SQL Managed Instance and SQL Server 2016-2022 to Fabric with free mirrored storage. Uniwise shares a customer story.
