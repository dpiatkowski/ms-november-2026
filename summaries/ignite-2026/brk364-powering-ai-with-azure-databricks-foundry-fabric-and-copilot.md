# Powering AI with Azure Databricks, Foundry, Fabric, and Copilot

**Speaker(s):** Anavi Nahar, David Meyer

## Summary

Microsoft and Databricks describe powering AI with Azure Databricks integrated with the Microsoft ecosystem (Fabric, OneLake, Power BI, Foundry, Copilot Studio, Agent 365, Entra ID, GitHub, Teams and Excel). The pitch is consolidating data in open formats (Delta and Iceberg, one copy) with a unified lakehouse (Lakeflow ingestion, Lakebase for Postgres transactions) and unified data and AI governance through Unity Catalog and Unity Gateway (AI spend budgets, compliance and audit).

Announcements include a Private Network Gateway on Azure (public preview) that replaces one private link per resource with a single gateway to a customer network, Genie as a data-smart AI coworker and agentic apps, and OneLake mirroring to unify catalogs.
