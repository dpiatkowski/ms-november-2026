# Voice agents in Microsoft Foundry: Prototype to production in 45 mins

**Speaker(s):** Yiwen Rong, Archer Zhao, Marvin Hsu, Matt Landis

## Summary

The session covers taking voice agents from prototype to production in Microsoft Foundry. It cites market figures (IDC, Metrigy, Grand View Research) and notes that only about a quarter of enterprises have scaled voice agents in even one function.

Speech announcements include generally available speech-to-text enhancements (native multilingual transcription in 50+ languages, multi-channel support, faster fast transcription, MAI-Transcribe-2 and an on-prem container), HD voices v3 and a VASA-2 photo avatar in public preview, and a refreshed LLM-based Live Interpreter API (30% fewer translation errors versus the prior version, about 3 seconds latency, personal voice preserved).

Voice Agents in Foundry offer a choice of models (GPT-Live-1, Microsoft-Realtime-Flash-1), full lifecycle management for prompt or hosted agents with knowledge, memory, tools and guardrails, and native SIP telephony integration, with customer examples from ASUS and others.
