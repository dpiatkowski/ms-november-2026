# From tool to teammate: Persistent agents for shared processes in Copilot Studio

**Speaker(s):** Matt Hidinger, Evan Lew

## Summary

The session presents Copilot Studio agents as persistent teammates for shared processes. It organizes the story around three ideas: collaborates like a colleague, is equipped like an employee, and learns on the job.

Agent Accounts (Frontier public, December 2026) give an agent its own Entra ID identity, mailbox, calendar and presence so it can be emailed, added to Teams chats, invited to meetings or @mentioned in Word, Excel and PowerPoint, and governed with Conditional Access, Purview DLP and sign-in logs. Equipping features include shared skills (available now), plugins (November 2026), computer use in a cloud browser or PC, and MCP apps; memory the user can manage and approved recommendations cover learning. Cost controls show credits per conversation, per-agent limits and environment-level allocation. The session also contrasts Agent Accounts with Microsoft Autopilot.
