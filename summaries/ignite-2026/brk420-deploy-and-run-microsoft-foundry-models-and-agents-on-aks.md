# Deploy and run Microsoft Foundry models and agents on AKS

**Speaker(s):** Brendan Burns, Jorge Palma

## Summary

The session covers deploying and running Foundry models and agents on AKS. It cites Gartner forecasts (growth in AI-optimized IaaS spending, Kubernetes as the default for AI workloads, open-weight model share and distributed AI deployment) and lists the complexity of production AI: choosing and running models (Ray, Kaito, vLLM, Kueue), deploying agents with identity and isolation, GPU provisioning, caching and observability.

Announced is AKS AI Manager for Foundry, offering workload-aware configuration, simplified inference deployment and optimized performance per model, so Foundry and open-weight models run on Kubernetes with existing tools. Foundry hosted agents on AKS keep the Foundry developer experience under the customer's network, policy and capacity controls, with each session isolated in its own micro-VM.
