# Run on it, Build on it: Digital Natives Scaling with M365​

**Speaker(s):** Dmitriy Bromberg, Pramod Nadakuditi

## Summary

The session shows how digital natives "run on" and "build on" Microsoft 365, using Litera (legal tech) as the single customer story. Run on it: Microsoft 365 E7 (E5 plus Entra Suite, Copilot and Agent 365) lets startups consolidate tools (the slides name Workspace, Slack, Zoom and Okta), govern agents in one registry, apply Zero Trust and use Copilot with model choice inside the tenant. Build on it: reach customers through plugins, MCP servers, Copilot agents, Work IQ APIs and Marketplace.

Litera describes modernizing from VSTO/COM add-ins to Office Add-ins and a cloud-native multi-tenant platform, launching its legal agent Lito (later moved to Microsoft Agent Framework) and exposing capabilities to Copilot through MCP. As customer zero it governs agents built on different platforms in Agent 365 and reports AI contributes to 76% of merged pull requests (customer-reported).
