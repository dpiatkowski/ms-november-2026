# More Human Value

**Speaker(s):** Justin Thenutiai

## Summary

The session argues that as execution becomes abundant, judgment becomes scarce, so leaders must design work around human intelligence. Leaders should name decisions that must stay human-led and sort work into uniquely human (high stakes, ambiguous, values in tension), AI-assisted (preparation, synthesis, options) and agent-driven (stable rules, reversible actions, clear escalation), starting from a clean-slate view of how work really runs.

Three choices follow: design the system rather than the tool, get people ready as work changes (an AI fluency layer of six behaviors: delegation, description, discernment, diligence, depth and diffusion), and change the system around judgment through behaviors, incentives, change management and leader modeling. Workflow examples cover software engineering, customer support and business writing, with a note on Microsoft's own workforce planning approach.
