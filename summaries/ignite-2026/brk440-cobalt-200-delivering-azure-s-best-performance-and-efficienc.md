# Cobalt 200: Delivering Azure's best performance and efficiency

**Speaker(s):** Amar Dhamdhere, Pat Stemen, Vadim Filanovsky

## Summary

The session presents Azure Cobalt 200 VMs, generally available and deploying to 23 regions by the end of 2026, with the slides claiming 50% higher performance than the previous generation and Azure's best price-performance. Cobalt is Microsoft-designed silicon built on Arm cores, optimized together with rack, power, networking and Azure Boost.

Design process: map Azure workloads to 140+ benchmarks, build a rack-scale model of silicon, power and cost, then tune for performance per TCO. Specs shown include 132 Arm Neoverse V3 cores on TSMC 3nm, 3 MB L2 per core, 192 MB L3, default memory encryption, on-die compression and cryptography accelerators (about 30% of reference workloads use them) and per-core voltage and frequency control with opportunistic performance up to 3.6 GHz.
