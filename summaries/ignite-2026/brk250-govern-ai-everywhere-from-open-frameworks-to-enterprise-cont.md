# Govern AI everywhere: From open frameworks to enterprise control

**Speaker(s):** Mohamed Elmergawi, Mehrnoosh Sameki, Manmeet Dhhillon, José Mejias

## Summary

The session covers governing AI agents across open frameworks and clouds. It cites 50M+ agents registered in Microsoft Agent 365 (up 30%+ quarter over quarter), an IDC projection of 2.2B active agents by 2030, and surveys showing many organizations have seen unintended agent actions.

The model is policy, enforce, evaluate, evidence. Using a fictional bank with a customer assistant, investment helper and advisor copilot, it shows how compliance, security, IT, developers and business owners each own rules (for example human approval over $10K transfers, no PII in responses). Announced in public preview are agent controls: define a policy once and every checkpoint in an agent run (user input, model call, tool call and output) can allow, transform, deny or escalate, built on the open Agent Control Specification and working across frameworks and clouds, with Foundry and Agent 365 integrations coming soon.
