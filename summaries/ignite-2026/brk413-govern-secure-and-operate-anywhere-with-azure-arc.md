# Govern, secure, and operate anywhere with Azure Arc

**Speaker(s):** Vlad Joanovic, Meagan McCrory

## Summary

The session covers governing, securing and operating distributed infrastructure with Azure Arc as a central control plane, citing Gartner on data increasingly created and processed outside the data center and cloud. Four scenarios are described: central management across a distributed estate, building and deploying apps across locations, collecting and analyzing device data, and fully managed infrastructure at distributed sites.

Arc lets teams see everything (one searchable inventory of servers, clusters and databases), simplify operations (Update Manager, Policy, Defender, Monitor, Sentinel) and run apps and data anywhere, with organizations managing over 20M resources. Announcements include a Configuration Manager connector enabled by Azure Arc (preview) to bring Configuration Manager resources into Azure, and a demo of onboarding and discovery.
