# Modernize on-prem VDI with Azure Virtual Desktop and Windows 365

**Speaker(s):** Beverley Ashton, Roop Chevuri, Colin McGerty, Shyam Pitchaimuthu

## Summary

The session addresses modernizing on-premises VDI with Azure Virtual Desktop (AVD) and Windows 365, citing pressures such as licensing costs (Unisphere Research for Rimini Street), server price increases of 50% or more (Gartner, February 2026) and user interruptions (Ivanti). It argues for a third way between the status quo and all-at-once transformation: modernize step by step.

Benefits listed are built-in Zero Trust, a local-feeling experience, one control plane in Intune and scale on demand, with Microsoft noted as a Leader in the Gartner Magic Quadrant for DaaS (August 2026). Guidance on choosing AVD (granular control, consumption pricing, VDI expertise) versus Windows 365 (SaaS simplicity, predictable per-user pricing) follows, with a customer roundtable from WTW and Chevron addressing cost, sovereignty, performance and migration concerns.
