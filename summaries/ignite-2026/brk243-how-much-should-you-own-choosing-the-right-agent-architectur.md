# How much should you own? Choosing the right agent architecture

**Speaker(s):** Glenn Condron, Amanda Foster, Lakshmi Ramakrishnan, Jeffrey Quesnelle

## Summary

The session helps teams decide how much of an agent to own in Foundry Agent Service, which spans build, deploy and operate with Foundry Control Plane and Agent 365 for governance. Two agent types are contrasted: declarative/prompt agents (model, instructions, tools and knowledge, with Microsoft maintaining the orchestration loop, including a Copilot harness in public preview) and hosted agents (your own code and container in any framework, such as Microsoft Agent Framework, LangGraph or third-party, on managed infrastructure). Voice is described as a modality that works with either.

A demo builds two agents on one platform: a hosted LangGraph daily-briefing agent and a no-code site-safety agent, both using Foundry IQ for company rules and published to Teams and Microsoft 365 Copilot, with agent identities, tracing and private networking. Grounding (Microsoft IQ, Foundry tools, memory) and optimization (observability, agent optimizer) are covered, and Nous Research's open-source Hermes Agent is shown as a partner example. Some capabilities are in preview.
