# Building sovereign private cloud for mission-critical environments

**Speaker(s):** Sydney Bruckmann, Meena Gowdar, Matt Dacquisto

## Summary

The session covers building Microsoft Sovereign Private Cloud for mission-critical environments on Azure Local, within a Microsoft Sovereign Cloud spanning sovereign public cloud, sovereign private cloud and a partner ecosystem. The private cloud stack includes Foundry Local, Microsoft 365 Local, GitHub Enterprise Local, Azure Virtual Desktop, SQL Server, Blob Storage, DocumentDB, VMs and AKS, in connected or disconnected modes with Azure-based management.

Announcements include re-homing an Azure Local instance between control planes without workload downtime (preview; only the management plane moves, e.g. connected to disconnected) and multitenancy (coming soon) with dedicated or shared infrastructure, per-tenant identity and showback metrics. A transit-district customer (GGBHTD) shares its experience.
