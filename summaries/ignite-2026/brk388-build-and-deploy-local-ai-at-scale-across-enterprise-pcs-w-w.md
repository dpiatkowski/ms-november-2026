# Build and deploy local AI at scale across enterprise PCs w/ Windows ML

**Speaker(s):** Daniel Freedman, Pawan Tahiliani, Anastasiya Tarnouskaya

## Summary

The session covers Windows ML, a generally available local AI inferencing framework for Windows built on ONNX Runtime with hardware-vendor execution providers across GPU, NPU and CPU, a shared system copy for all apps, and a Windows ML CLI (with agent skills) to convert, analyze, optimize, quantize and benchmark models. It cites over a billion local-AI-capable Windows 11 PCs and 60K+ ONNX and 260K+ PyTorch models on Hugging Face.

Experimental items include Windows-native runtime APIs and running GGUF open-source models through llama.cpp with Windows ML. It frames hybrid intelligence (local only, hybrid, cloud only) and demos a customer-service scenario using an embedding model optimized through the CLI to match help articles in milliseconds.
