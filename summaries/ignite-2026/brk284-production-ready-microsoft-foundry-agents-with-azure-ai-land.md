# Production-ready Microsoft Foundry agents with Azure AI Landing Zones

**Speaker(s):** Ofek Ben Eliezer, Vlad Borys, Ben Brauer, Paulo Lacerda

## Summary

The session sets out how to take Microsoft Foundry agents from proof of concept to production using Azure AI Landing Zones, a secure, repeatable environment for agents aligned with the Cloud Adoption Framework and Well-Architected Framework. It names six roadblocks between demo and production: an AI center of excellence, AI governance, landing-zone infrastructure, AI security and trust, AgentOps (CI/CD, tracing, evaluations) and solution optimization.

The story told is a retailer whose returns-assistant POC worked in two weeks but stalled for months because networking, private endpoints and capacity were built by hand and security would not approve a bespoke setup. The flow covers a design framework and reference architecture, then an extensible implementation using agent landing zones and AI gateway landing zones, with KPIs such as time to provision a new agent environment and the share of agents in the governed zone.
