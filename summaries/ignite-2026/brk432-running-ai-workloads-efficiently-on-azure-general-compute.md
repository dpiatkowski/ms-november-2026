# Running AI workloads efficiently on Azure general compute

**Speaker(s):** Stefanie Lemon, Max Uritsky, Vadim Filanovsky

## Summary

The session covers running AI workloads efficiently on Azure general compute. It classifies AI workloads (training, inference, agentic systems) by dominant constraint and suggests starting with the likely constraint and validating under representative load, for example CPU and containers for RAG and agent tool execution.

Cobalt 200 Arm-based VMs are presented with up to 50% higher CPU performance than Cobalt 100, large caches, compression and cryptography offload and Azure Boost integration, with new series matched to AI pipeline stages (Dplsv7 for microservices and tool execution, Dpsv7 for orchestration and RAG, Epsv7 for embeddings and caches, Mpsv4 for large RAG and vector databases, Lpsv5 for preprocessing and indexing), and faster sandbox creation and higher density for agentic compute. OpenAI shares how it uses Azure general compute.
