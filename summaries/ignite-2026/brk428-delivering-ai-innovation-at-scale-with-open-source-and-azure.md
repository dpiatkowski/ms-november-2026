# Delivering AI innovation at scale with Open Source and Azure

**Speaker(s):** Lachie Evenson, Jim Perrin, Jef Spaleta

## Summary

The session covers delivering AI innovation at scale with open source and Azure. It argues organizations should choose among proprietary frontier, lower-cost or specialized and open-weight models, and run AI where they choose (on-premises, portable or public cloud), building a learning loop on open layers: Phi open weights, Radius, Kubernetes with KAITO and AI Runway, and Azure Linux and Flatcar.

It reviews Microsoft's open source stewardship (the slides cite 60K+ Microsoft developers active on GitHub and Kubernetes and CNCF contributions) and a history of Linux involvement, and includes a Red Hat discussion of what Azure and Fedora get from each other. The slides state hundreds of Microsoft services and OpenAI and ChatGPT run on Linux in Azure.
