# Token economics: Get more from your production AI budget

**Speaker(s):** Chris Hoder, Kosti Vasilakakis, SukYeon Jung, Alex Tyrrell

## Summary

The session addresses token economics for production agents: price per token is falling but tokens per task are rising, so bills do not fall. It frames questions for developers (cheapest model that holds the quality bar), platform teams (where tokens go) and finance (cost per outcome).

A demo follows a fictional bank (Woodgrove) whose fraud-case agent got more expensive after version 2 shipped; Foundry Control Plane, cost views, traces, insights and Agent Optimizer are used to find why, then levers are pulled: model choice, traffic, offer shape and scale, plus cost controls. Wolters Kluwer's CTO describes defining usefulness first and then reducing cost through evals, hill-climbing prompts and caching (a shared cacheable prefix with cache rates above 90%, plus semantic caching), shown for UpToDate Expert AI and CCH Axcess.
