# What's new and what's next in Azure Storage​

**Speaker(s):** Aung Oo, Vybava Ramadoss, David Meyer

## Summary

The session covers what is new in Azure Storage for AI and mission-critical workloads: block storage (Ultra, Premium SSD v2, Elastic SAN), object (Blob, Data Lake), file (Files, NetApp Files, Managed Lustre) and data management and migration services. The slides describe storage as supporting OpenAI training at petabits-per-second scale and as the source behind most vector content for Foundry IQ and Azure AI Search.

Announcements include multiple storage fault domains within an availability zone via VMSS Flex (preview). The session maps scale requirements across mission-critical apps, data platforms and AI/agents (for example tens of Tbps for training, under 5 ms P99 agent data access) and includes a Databricks partner segment.
