# Agentic media operations: Run at scale

**Speaker(s):** Kanio Dimitrov, Don Hejna, Ashok Kalidas

## Summary

Kantar and Microsoft describe agentic media operations built on LINK AI, Kantar's model for predicting ad effectiveness (40M+ survey-tested ads, scoring six drivers: memorability, differentiation, branding, meaningfulness, messaging and conversion). The goal is to extend LINK AI from evaluating ads to optimizing them through an agentic loop where graders score, recommend and regenerate.

Scaling the graders required speed, granularity (keyframes, scenes and whole videos) and reliability at volume: standardized ML services with vLLM inference, Dapr Workflow for durable orchestration, tiered live and batch queues on Azure Service Bus, and load testing with OpenTelemetry and Azure Monitor, running on AKS with open-source models on GPUs. Figures are customer-reported.
