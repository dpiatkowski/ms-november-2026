# Protect data and accelerate AI adoption with Microsoft Purview

**Speaker(s):** Kim Kunes, Herain Oberoi, Nick Granack

## Summary

The session explains how Purview is evolving to secure data for AI. The slides argue manual classification cannot keep up with scale (the example calculation: 160 billion sensitive files across Microsoft's 500 largest customers, with 2 billion new SharePoint files a day), so Microsoft built a "classifier factory" where AI reasoning models review classifier decisions, finding false positives and misses to improve accuracy.

New items: enhanced built-in sensitive information types starting with the 100+ most popular classifiers (available from January 2027), recurring classification refresh up to twice a year (public preview January 2027, to be included in E5), auto-labeling limits raised to 500,000 files a day and 20 million simulated matches (generally available), adaptive scopes (public preview) and default library labels.
