# Raising the Bar for Windows Quality: Built with Your Feedback

**Speaker(s):** Ian LeGrow, Robin Seiler

## Summary

The session responds to enterprise feedback on Windows 11 quality (performance, reliability and drivers, sign-in, updates and new PC setup). On performance it describes leaner memory use across Windows and Microsoft apps (360 MB less memory committed for Excel, Outlook, PowerPoint and Word combined; about 550 MB from Defender, Purview and OneDrive background services; sleeping Edge tabs after 15 minutes) and claims multitasking up to 40% more responsive; these are Microsoft-reported.

On reliability it describes the Driver Quality Initiative (architecture, trust, lifecycle, measurement), moving security software and more drivers out of the kernel into user mode via the Windows endpoint security platform (generally available in 25H2 and 26H2) and the User-Mode Driver Framework, with claims of fewer File Explorer hangs and fewer USB4 display docking failures. Sign-in, Windows Update and craft (Start, taskbar, search) improvements are also covered.
