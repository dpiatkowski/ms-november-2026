# Getting the most out of GitHub Copilot and Azure DevOps

**Speaker(s):** Dave Burnison, Dan Hellem

## Summary

The session shows how to use GitHub Copilot with Azure DevOps without first migrating repositories. Topics: the Azure DevOps remote MCP server (generally available since August, with local and remote support), an Azure DevOps plugin for Microsoft Copilot Cowork, Azure DevOps integration in the GitHub Copilot app (public preview), Copilot code review for Azure Repos (generally available, with custom instructions, effort level and billing to an Azure subscription), and Copilot Autofix for GitHub Advanced Security for Azure DevOps (public preview, with batch selection coming soon).

For teams ready to move, Enterprise Live Migrations is generally available, offering continuous sync, under-30-minute cutover and full fidelity to GitHub Enterprise Cloud with data residency. The slides also recommend building a deliberate "AI infrastructure" layer of instructions files, skills, custom agents and MCP servers.
