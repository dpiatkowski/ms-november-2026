# Govern Once, Use Everywhere: Scale Copilot with Microsoft Plugin Registry

**Speaker(s):** Rachit Malik, Mandy Whaley

## Summary

The session explains plugins as the packaging unit for Copilot: skills and tools are building blocks, agents orchestrate, and plugins distribute them together through a Microsoft plugin registry governed in Agent 365 and the Microsoft 365 admin center (enable, block, assign users or groups, usage insights).

A running scenario asks whether a launch can go ahead next week. Demos cover discovering a plugin in Copilot (Chat, Cowork, Code and Autopilot), building a custom plugin with GitHub Copilot and Work IQ Developer Tools around a remote MCP server, then validating, previewing, sharing and publishing to a tenant or cross-tenant, and governing it by reviewing publisher, version, packaged skill, MCP tools and audience. A final demo uses an Adobe plugin to prepare launch assets. Related sessions named: BRK237 and LTG1220.
