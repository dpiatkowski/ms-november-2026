# Hybrid Intelligence: Making It Real with Windows PCs

**Speaker(s):** Mark Linton, Kurt Stevenson

## Summary

The session explains hybrid intelligence on Windows PCs: running some AI work locally and some in the cloud, with the work deciding where it runs by capability, volume, speed, data sensitivity and connectivity. It argues each PC purchase matters more as PCs become part of AI infrastructure, with Gartner and IDC figures on distributed production AI and agent growth.

Capabilities include a secure platform for agents (Agent 365, Microsoft Execution Containers, Intune, Defender, Purview, Entra Agent ID), Copilot using local files, actions and local models (coming soon), and Copilot Fusion offloading to a PC with GitHub Copilot. Memory sets what a PC can run (16 GB for 7B models up to 128 GB for 100B+ models like MAI Code Flash, and DGX Station for Windows up to 748 GB, coming in Q4 from several OEMs). Insight shares a partner view; model-size guidance is from Microsoft planning guidance and NVIDIA announcements.
