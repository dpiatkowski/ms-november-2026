# Host apps from anywhere with the new Copilot Managed Runtime

**Speaker(s):** Emma Cooper, Clay Wesener, Malavika Balachandran Tadeusz, Alexis Barker, Lan Roche Roche

## Summary

The session announces Copilot Managed Runtime as generally available (as of November 17), a Microsoft-managed service for running apps built in Copilot Studio, Copilot Code, Copilot Cowork or third-party SDK-compatible tools, with business data and identity built in (1,500+ connectors, Dataverse, SharePoint, Excel, Fabric, Work IQ) and centralized management of access, policies, usage and health in the Microsoft 365 admin center.

Prompts shown include turning a meeting recording into an issue tracker, a deal desk app from open opportunities, or a safety audit app from site inspection photos. Apps are described as evolving from static to agentic (agent-backed, still governed). Also announced: Copilot Studio agents and workflows built locally with Git-based source control (public preview) and code agents (early-access preview), with apps in Copilot Code in Frontier. Lovable also appears as a speaker.
