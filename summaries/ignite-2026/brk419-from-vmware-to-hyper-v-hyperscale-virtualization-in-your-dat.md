# From VMware to Hyper-V: Hyperscale virtualization in your datacenter

**Speaker(s):** Davanna White, Jeff Woolsey, Philip Moss

## Summary

The session presents Windows Server Hyper-V with Windows Admin Center virtualization mode (vMode) as a destination for organizations leaving VMware, as part of a Microsoft strategy that places each workload either in Azure (modernize with PaaS, or rehost and refactor with Azure Catalyst) or on-premises on Windows Server, Hyper-V and vMode. Pressures cited include licensing and packaging changes, cost predictability and migration urgency.

It positions Hyper-V as already included in Windows Server and deployed at large scale, with central fabric management without System Center, support for SAN, NAS, HCI and SDN architectures, demos, and an outlook that includes Windows Server 2028 capabilities across security, infrastructure, management and hybrid intelligence.
