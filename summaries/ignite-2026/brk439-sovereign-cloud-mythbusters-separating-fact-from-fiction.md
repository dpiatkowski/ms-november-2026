# Sovereign cloud mythbusters: Separating fact from fiction

**Speaker(s):** Rick Claus, Pierre Roman

## Summary

The session is a myth-busting format on sovereign cloud with an audience vote on six myths. It frames sovereignty as four dimensions (data, keys, operations, regulations) configured workload by workload, not a single product, and walks through deployment options (sovereign public cloud, Azure Local private cloud, national partner clouds such as Bleu in France and Delos Cloud in Germany).

Verdicts shown: "digital sovereignty requires a local cloud provider" is busted (tradeoffs include lagging commercial features); "data residency alone addresses sovereignty" is busted, with gotchas that some services are non-regional by design (Azure Front Door, Traffic Manager, DNS, Policy) and not every service supports Managed HSM keys; and "disconnected is always more secure" is busted, since you become your own cloud operator for patching, DR and monitoring. Remaining myths on AI and provider access are covered in the session.
