# The evolution of Azure infrastructure for AI models, apps, and agents

**Speaker(s):** Narayan Annamalai, Aung Oo, Max Uritsky

## Summary

Azure compute, storage and networking leaders describe how Azure infrastructure is evolving for AI models, apps and agents. They separate what training (parallel GPU compute, interconnects, checkpointing), inference (right-sized capacity, fast model loading, KV and context caching) and agentic AI (balanced CPU and GPU, secure connectivity, persistent state, identity and isolation) each need from one foundation of workload-aware compute, high-performance networking, intelligent storage and security.

Platform investments named include Azure AI Substrate, Cobalt 200 VMs, Azure Boost, AKS AI Manager, AI PoPs, AI Gateway, an inference gateway on Application Gateway for Containers, Azure Firewall for AI, cross-region RDMA, Azure Blob Turbo tier, Azure Managed Lustre, a distributed cache for cloud storage and fast pod snapshot/restore. The session also frames modernizing an application estate that mixes mission-critical, cloud-native and AI-enabled workloads.
