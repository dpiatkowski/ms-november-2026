# Modernize legacy integration with Azure Logic Apps

**Speaker(s):** Harold Campos, Divya Swarnkar, Fabian Dworschak

## Summary

The session makes the case for modernizing legacy integration with Azure Logic Apps, noting BizTalk Server 2020 is the final release with end of sale on March 31, 2027, end of mainstream support on April 12, 2028 and planned end of optional paid extended support on April 10, 2030 (subject to eligibility and terms). Logic Apps is positioned as less code to maintain than AI-generated glue code, with 1,400+ pre-tested connectors, durable stateful runs, deterministic workflows plus agent reasoning, and secure-by-default identity.

For sovereignty and latency needs, Standard workflows can run on your own infrastructure via the hybrid deployment model with Azure Arc. New in Logic Apps Standard (preview items include AI-assisted data mapping that reuses BizTalk maps) are SOAP and MSMQ connectors, a unified dashboard, a rules engine XML facts action, HL7 connector and a migration agent. Schaeffler shares a customer story.
