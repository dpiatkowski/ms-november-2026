# What's new in Copilot Studio

**Speaker(s):** Alice Appleton, Jason Moore

## Summary

The session is a broad tour of what is new in Copilot Studio, organized into three pillars: maker experience, agent capabilities, and governance and FinOps. Maker updates include a simpler single agent designer (instructions, model, tools, skills, knowledge, memory, with evaluate and monitor built in), workflows with agent nodes, apps alongside agents and workflows on Copilot Managed Runtime (preview), and natural-language building (preview) from Cowork, Copilot Studio or any MCP-compliant CLI.

Agent capabilities include the Microsoft Copilot harness (quality +11.9 to +47.5 points and input tokens 47.8K to 26.5K in the slides' same-model comparison), skills published to the Microsoft plugin registry and governed in Agent 365, per-user memory that users can view or delete, agent identity, Auto model selection and MCP apps rendering real UI. Governance and FinOps cover evaluations, monitoring and Copilot credit management. Preview labels are from the slides.
