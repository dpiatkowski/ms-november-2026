# Copilot Code: Build custom solutions for your unique needs

**Speaker(s):** Andrew Gillies, Marc Wautier

## Summary

Copilot Code is presented as the "Build" mode in Copilot's modes of work (Assist/Chat, Delegate/Cowork, Build/Code, Automate/Autopilots). It aims to make coding accessible to non-developers by building from the user's own files, meetings and chats, publishing from protected sandboxes with governed sharing, and connecting GitHub or Azure DevOps for developer extension.

The session's customer example is RegalRexnord, where HR built a pulse-check app without a developer so leaders keep their talent commitments visible after the annual review, with quarterly check-ins and a real-time view for the CFO. A demo uses a fictional furniture retailer (Lakeshore Retail) running on Dynamics 365 Commerce, Power BI, Azure DevOps and Microsoft 365.

The guidance is to lead with the outcome, use work data you already have, and start small (own tool, then team pilot, then engineering). Copilot Code sits on Copilot's privacy, security and compliance foundation, with controls that vary by subscription plan.
