# AI in the Flow of Work: OneDrive for the AI Era

**Speaker(s):** Kalpana Berman, Gaia Carini, Sophia Peng, Denise Jay

## Summary

The session presents OneDrive as the file system for the AI era, built on SharePoint's foundation, with Copilot turning files into outcomes: search and organize content, autofill SharePoint metadata, create and collaborate on HTML and Markdown files, and save skills (marked Frontier, available now).

Capital Group describes its path to Copilot: moving network drives to OneDrive and SharePoint (167 TB, 158+ million files as of June 30, 2026) so Copilot is grounded in the data. Lessons: data access drives results, focus on benefits rather than mandates, and let people start with comfortable scenarios.

Other announcements include a refreshed Libraries view, Shortcuts on Demand (private preview, December 2026), hiding the Sync button per site (January 2027), macOS 1M-item sync and a sync CLI, and a new sharing model with a single "hero link" per item (link expiration due February 2027), plus oversharing and inactive-file reports.
