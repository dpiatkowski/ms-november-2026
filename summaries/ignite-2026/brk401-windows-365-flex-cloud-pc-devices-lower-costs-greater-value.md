# Windows 365 Flex & Cloud PC Devices: Lower Costs, Greater Value

**Speaker(s):** José Lara Silva, Tania Mariscal, Raid El Badarin-Deriy

## Summary

The session covers Windows 365 Flex (the renamed Frontline) and Cloud PC devices. Enterprise suits full-time users with one Cloud PC per license; Flex dedicated gives part-time workers up to three Cloud PCs per license with one in use at a time; Flex shared lets intermittent or shift users share a pool where IT manages capacity (Cloud PC size, concurrency, number) while Microsoft manages the pooled infrastructure, in contrast to traditional pooled VDI.

Flex Shared is described as non-persistent ready: a clean desktop at every sign-in via snapshot-based reset to a prepared baseline, with user experience sync (included with the Flex license, limits apply) to roam settings and data. Use cases include shift workstations, retail stations and third-party workers. Telefónica Deutschland shares a customer view.
