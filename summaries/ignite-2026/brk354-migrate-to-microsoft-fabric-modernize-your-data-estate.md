# Migrate to Microsoft Fabric: Modernize your data estate

**Speaker(s):** Rakesh Krishnan, Wee hyong Tok

## Summary

The session makes the case for migrating to Microsoft Fabric as an AI-native, unified data platform with a single SKU, OneLake, centralized security and governance, and Microsoft IQ context (Work IQ, Fabric IQ, Foundry IQ, Web IQ) powered by semantic models. It cites more than 44,000 Fabric customers.

It covers migration paths from Azure Data Factory, Azure Synapse (dedicated SQL pools, Spark), HDInsight, Power BI Premium and SQL Server analytic workloads, with built-in Microsoft tools for guided migration, TCO optimization through consolidation, modernized integration architecture and AI-powered development using Fabric MCP and Fabric skills. Industry figures are from the Work Trend Index, IDC and Deloitte.
