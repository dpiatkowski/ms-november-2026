# Claude Keeps Building: How coding agents in Foundry change software development

**Speaker(s):** Kevin Martin

## Summary

Anthropic's Claude Code lead describes how coding agents in Microsoft Foundry change software development: writing code became cheap, so cost moves to deciding what to build and checking it is right, which stresses processes built for slow coding (big PRs, few reviewers, gates at every step). Work runs in an inner loop (one engineer and Claude, minutes per turn) and an outer loop (PR review, CI, approval, org rules).

Two kinds of control are distinguished: non-deterministic guidance (CLAUDE.md, skills, prompts) that is usually followed but never guaranteed, and deterministic enforcement outside the model (hooks, deny rules, sandbox). Demos follow one ticket from Azure DevOps on a laptop with Claude Desktop on Foundry, through a PR loop where Claude Code in GitHub Actions reviews and a person approves, to shipping under organization-wide policies.
