# Beyond coding: Build next-gen agents with the Microsoft Copilot SDK

**Speaker(s):** Patrick Nikoletich, Steve Sanderson

## Summary

The session announces Microsoft Copilot SDK 2.0, which follows the GitHub Copilot SDK (GA in June) transitioning to the Microsoft Copilot SDK. The SDK is the programmatic interface to the Microsoft Copilot runtime and harness (planning, built-in tools, agents, skills, instructions, memory), runnable on a laptop, container, cloud or inside Copilot apps, with any inference (GitHub Copilot models, Foundry, local models or bring your own key). The harness already powers Copilot cloud agent, code review, IDEs, Cowork, Office apps, Azure Copilot, Foundry and Fabric.

New in 2.0: multi-tenant runtime, session-scoped identity, host-owned tools and policy, attach/detach/resume sessions, a Rust core embeddable via a C ABI and isolated container sandboxes. A demo launches an in-game shop using the managed-copilot-sdk reference implementation, with support, data and incident-commander agents. Deep dive follows in BRK277.
