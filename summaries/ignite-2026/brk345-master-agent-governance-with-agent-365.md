# Master Agent Governance with Agent 365

**Speaker(s):** Sneha Kohli, Mark Wahl, HC Jo

## Summary

The session argues that agent adoption is outpacing ownership: unlike a new hire, an ungoverned agent may lack an owner, a lifecycle, scoped access, approved tools and data, and an audit trail. Agent 365 is presented as the observability platform with four jobs (management, governance, security, business value), and the session goes deep on governance for IT, AI and security admins, including finding unregistered agents (VS Code extension agents, CLI coding agents, standalone runtimes) and deciding to register, scope or block them.

LG U+ describes its shift from building agents to trusting and operating them across Microsoft and non-Microsoft platforms, governing every agent with Agent 365. The telecom reports Copilot adoption within a month of rollout and plans in AI call agents and sovereign AI; figures are the customer's own.
