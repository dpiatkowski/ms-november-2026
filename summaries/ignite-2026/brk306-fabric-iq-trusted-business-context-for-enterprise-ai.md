# Fabric IQ: Trusted business context for enterprise AI

**Speaker(s):** Bogdan Crivat, Chafia Aouissi, Sara Vredevoogd, Hiroaki Kimura

## Summary

The session presents Fabric IQ as the trusted business-context layer within Microsoft IQ, built on OneLake (cross-cloud shortcuts and mirroring across Dataverse, AWS S3, Databricks, Snowflake and on-premises) and semantic models (the slides cite 35M+ regular users and 22 million+ semantic models). The framework is unify the data estate, process and harmonize data, curate semantic knowledge, and empower AI agents.

Announcements include Fabric IQ with Power BI as business context in Copilot Chat (generally available), a Fabric IQ plugin in Cowork, an MCP server, Ask-data in Excel, and previews in ChatGPT and Claude that ground answers in existing Power BI semantic models. It also describes working with Snowflake on Apache Ossie, an open semantic standard, so semantic context can be defined once and reused.
