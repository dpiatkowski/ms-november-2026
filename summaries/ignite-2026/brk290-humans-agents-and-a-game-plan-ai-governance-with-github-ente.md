# Humans, agents, and a game plan: AI governance with GitHub Enterprise

**Speaker(s):** Greg Padak, Amrita Yellepeddy

## Summary

The session covers AI governance with GitHub Enterprise around three north stars: delegate (decisions closer to teams and agent owners), enable (trust unlocks more capability) and simplify (connect policy, spend and insight). Four pillars frame the investment: managed settings (configuration as code for clients), server-side policy, observability and agentic administration.

Shipped or announced items include the Model Policy API for automating model mix across enterprise, organization and team scopes, global default policies for features, clients and models (open-weight models excluded from automatic enablement, explicit admin choices preserved), enterprise teams mode (preview) for granting extra model access to defined groups, agent session streaming (public preview), and Copilot Fusion, a model orchestrator that selects among only the models an enterprise has enabled. Organization-team client customization via plugin marketplaces is coming soon.
