# Build AI-powered Microsoft Fabric workflows with GitHub Copilot

**Speaker(s):** Kevin Pereira, Leslie Welch

## Summary

SHI shows how to build Microsoft Fabric workflows with GitHub Copilot. It explains that licensing has two separate meters: GitHub Copilot (Business $19, Enterprise $39 per user per month, with AI credits for chat and agent work, code completions not using credits) and Fabric capacity, which GitHub Copilot does not use but what it builds (notebooks, pipelines) does; Git integration needs a Fabric capacity and Fabric's own Copilot runs on F2 and above. The slides note pricing changes often.

For data engineers the demo builds notebooks, stored procedures and a bronze-to-gold pipeline; ideas to try include documenting inherited notebooks, writing data quality checks, validation queries and refactoring PySpark. For BI developers, uses include semantic model descriptions, ERD and documentation generation, explaining DAX, bulk naming standards and Best Practice Analyzer checks on every PR.
