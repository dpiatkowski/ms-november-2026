# Run secure agent loops in production with isolated sandboxes at scale

**Speaker(s):** Devanshi Joshi, Jan Kalis, Christian Flasshoff, Jeffrey Quesnelle

## Summary

The session covers running secure agent loops in production with isolated sandboxes. It cites Gartner survey data on the AI agent governance gap and argues sandboxes are the new infrastructure backbone: Azure Container Apps Sandboxes (generally available) provide hardware-isolated microVMs with networking and identity for short-lived and long-running agent workloads, with no idle compute cost, and underpin Foundry Agent Service, Copilot Studio, GitHub Copilot experiences and Azure SRE Agent.

Nous Research presents Hermes Agent (open source, self-improving, capturing successful workflows as reusable skills) and Hermes Enterprise, which adds governed skill promotion, model and spend routing, and control over memory and traces, running in an ACA sandbox boundary. Cognite shares industrial agent use cases.
