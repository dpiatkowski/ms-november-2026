# Humans to agents: Mission-critical starts with Azure SQL Hyperscale

**Speaker(s):** Anna Hoffman, Bob Ward, Anurag Batra, Michael Davidson

## Summary

The session reintroduces Azure SQL Database Hyperscale as cloud-native SQL at any scale (up to 128 TB and 192 vCores, no downtime scaling, no separate license fee, serverless with auto-pause, elastic pools) with better price-performance, HTAP read isolation and faster recovery. It announces a limited preview of cross-database querying for Hyperscale elastic pools, and cites benchmarks of better price-performance than AWS and up to 50% faster than Amazon Aurora PostgreSQL on a TPROC-C test (Microsoft-reported).

For AI apps and agents, Hyperscale includes JSON, vector and regex support, multi-model features, DiskANN and full-text with BM25, change event streaming, a SQL MCP server, a local container and agent skills. CDW describes replacing Excel-based enterprise architecture management with Hyperscale. Demos cover serverless, pools, cross-database queries and vector search.
