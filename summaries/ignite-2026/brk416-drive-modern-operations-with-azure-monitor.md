# Drive modern operations with Azure Monitor

**Speaker(s):** Rahul Bagaria, Evgeny Ternovsky

## Summary

The session covers Azure Monitor in the agentic era, with agent observability across Azure Monitor, Foundry and Agent 365 backed by a shared Microsoft OpenTelemetry distro. Announcements include per-agent details and fleet view, trace analytics (public preview), agent cost (private preview), external agent observation, an evaluations view bringing Foundry evals into Azure Monitor, annotations, safety evaluators, skill and cost optimization, and platform features such as protected tables, PII redaction, multimodal data inspection and a lower-cost SKU for agent telemetry. Code optimization is coming soon.

AI-driven troubleshooting is delivered by the Azure Copilot observability agent, native to Azure Monitor, which explores telemetry and turns noise into investigated issues with humans in control. A demo shows agent observability, and the session also connects technical health to business impact and cost.
