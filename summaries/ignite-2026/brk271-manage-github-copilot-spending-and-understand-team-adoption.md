# Manage GitHub Copilot spending and understand team adoption

**Speaker(s):** Dave Burnison, Pallavi Challa

## Summary

The session covers managing GitHub Copilot spending and adoption with an "inform, govern, guide" control plane. Inform: usage metrics API data (41 fields per user per day across IDE, CLI, cloud agent and code review, including AI credits used, skills, custom agents, MCP servers and third-party agents), data export to Azure or AWS (preview), and attributed cost per user and model.

Govern: enterprise, cost-center and individual budgets, AI credit pooling and spend caps, notifications before limits, budget increase requests and approvals, and budget-based fallback models, with delegated budget management coming. Guide: interpreting adoption phases and productivity trends and targeting enablement where teams need support. Preview and upcoming items are subject to change per the slides.
