# Secure by default. Azure's multilayered embedded security capabilities

**Speaker(s):** Vikas Bhatia, Mohamed Hassan, Ashish Jain

## Summary

The session describes Azure's multilayered security by default. It frames a continuous security loop (engineer, validate, observe, respond) and secure by design, default and operations, citing Microsoft Threat Intelligence scale figures from the slides.

Compute security topics include tenant isolation, Trusted Launch (Secure Boot, vTPM, measured boot, guest attestation, on by default for eligible new Gen2 VMs and VMSS), an image reference metadata-only mode (preview) to keep the recorded OS accurate after in-place upgrades, periodic update assessment for VMSS Uniform (public preview, reporting only, installation remains separate), and the Guest Proxy Agent with the Metadata Security Protocol to protect IMDS and WireServer. Network security speakers also contribute.
