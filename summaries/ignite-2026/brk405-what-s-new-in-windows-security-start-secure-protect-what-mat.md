# What's new in Windows security: Start secure, protect what matters, prepare for the AI era

**Speaker(s):** Saud Al-Mishari, Katharine Holdsworth

## Summary

The session covers what is new in Windows Security under three themes: start secure, protect what matters and prepare for AI. It describes AI speeding the vulnerability lifecycle (find earlier, fix faster, verify continuously) and quantum risk (hybrid ML-KEM and ML-DSA certificates, with long-lived data captured today and decrypted later), pointing to related sessions LTG1270 and LTG1240.

Start secure items: the hardware baseline (TPM 2.0, Secure boot, VBS) and Windows baseline protection with eight critical protections, administrator protection (standard user by default, Windows Hello elevation, no persistent admin token), the Windows endpoint security platform and Driver Quality Initiative, NTLM reduction (IAKerb and LocalKDC), and Windows Autopatch with hotpatch for fewer restarts. Protect-what-matters items include passwordless, declarative management and BitLocker improvements.
