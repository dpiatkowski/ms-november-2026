# Agents in production: Observe, evaluate, and optimize with Foundry

**Speaker(s):** Han Che, Divya Chirasani, Deepraj Khot

## Summary

The session argues agents need more than uptime monitoring: failures show up as behavior (wrong tool, ignored policy, unfinished task), not errors. It frames three stages (build, production, scale) and a layered evaluation approach: code-based graders for machine-checkable correctness, model-based LLM judges for semantic quality, and human expert review for high-stakes or ambiguous cases.

Foundry capabilities covered include automatic tracing for prompt and hosted agents, new generally available instrumentation for external agents through a Microsoft OpenTelemetry distro (Azure Monitor and Application Insights), evaluation datasets built from traces, rubric evaluators that now support safety checks, decision models for continuous evaluation at scale, Insights (generally available) to find unknown issues, annotations by experts on production traces, and Agent Optimizer to turn an insight into a tested fix, including optimizing skills and cost. Some items are in preview. Tata Consultancy Services shares a customer view.
