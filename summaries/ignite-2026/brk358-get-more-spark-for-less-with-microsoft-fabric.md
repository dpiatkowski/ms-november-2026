# Get more Spark for less with Microsoft Fabric

**Speaker(s):** Ashit Gosalia, Santhosh Ravindran

## Summary

The session gives practical guidance for running Spark in Microsoft Fabric for less. It covers sizing (match node size to workload, scale one dimension at a time), billing choices (fixed capacity for steady workloads, Autoscale Billing for bursty Spark, or a hybrid with reserved instances) and high-concurrency session sharing (up to 50 shared sessions in notebooks, Livy high concurrency, around 5-second starts with managed VNets) to lower cost per job.

Security topics include outbound access protection, private link and managed private endpoints, workspace-level private link, row- and column-level security (now generally available in Spark) and customer-managed keys (shuffle data coming soon). The session also covers library management (quick versus full mode), job scheduling, tuning, monitoring, and test and deploy.
