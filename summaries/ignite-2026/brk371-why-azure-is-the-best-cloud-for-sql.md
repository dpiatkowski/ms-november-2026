# Why Azure is the best cloud for SQL

**Speaker(s):** Pam Lahoud, Priya Sathy, Sameer Agarwal

## Summary

The session argues the database foundation is a business decision: applications need room to grow, innovate (analytics, search, retrieval, AI), scale without permanent overprovisioning, and stay available. It presents Microsoft SQL (Azure SQL, SQL Server 2025, SQL database in Fabric) as one consistent SQL for the AI era and makes the case for modernizing now, citing AI readiness, security (IBM figures of a $4.88M average breach cost and 64 days to contain) and cost.

It lays out two paths, modernizing existing applications and building new ones, with Azure SQL Database Hyperscale supporting both, and describes choosing between IaaS (SQL Server on Azure VMs, for quick lift-and-shift or OS control) and PaaS (fully managed, always current, 99.995% SLA), including a phased migration example. Agentic modernization is also covered.
