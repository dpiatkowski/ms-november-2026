# Foundry IQ: Knowledge graphs for better enterprise context

**Speaker(s):** Matt Gotteiner, Lewis Liu

## Summary

The session introduces a knowledge graph feature in Foundry IQ for questions where answers hide in relationships or span themes. It describes a progression of data representations, from keyword and vector indexes to topic graphs (relevant variety, lower cost) and entity graphs (explicit links, highest precision), with one query able to use both graphs alongside existing indexes in the knowledge base.

A demo uses an earnings-analyst agent over Microsoft earnings calls (FY14-FY26): topics identify themes across 49 calls, entity traversal links analyst questions to executives and drivers, and snippets from 841 chunks ground a cited answer. The session ends with how to get started.
