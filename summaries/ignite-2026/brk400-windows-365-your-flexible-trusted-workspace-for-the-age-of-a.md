# Windows 365 – Your flexible, trusted workspace for the age of AI

**Speaker(s):** Bhavya Chopra, Mayank Verma, Ed Collins, Shyam Pitchaimuthu

## Summary

The session presents Windows 365 as a flexible, trusted workspace for people and agents, with elastic Cloud PCs (4-128 vCPU, up to 2 TB storage, GPU options), Enterprise, Flex and Reserve models, AVD Hybrid and devices designed for Windows 365. New at Ignite: Direct Stream, a streaming technology to make Cloud PCs feel local (fast connection, performance optimization, reliability, secure transport), NVIDIA collaboration for GPU-accelerated streaming (preview), a Windows 365 Link and Logitech peripherals bundle, and developer Cloud PCs with support for running AI models locally (preview).

For agents, it covers a computer-use tool in Copilot Studio and Agent 365 with on-demand pay-as-you-go Cloud PCs and always-available Cloud PCs billed with Copilot Credits, plus preview items such as Foundry support and persistent Cloud PCs for autonomous agents. Lululemon and Chevron share customer views.
