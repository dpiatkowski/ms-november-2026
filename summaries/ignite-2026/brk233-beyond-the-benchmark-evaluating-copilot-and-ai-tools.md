# Beyond the Benchmark: Evaluating Copilot and AI Tools

**Speaker(s):** Bas Brekelmans, Amber Waisanen

## Summary

The session argues that AI value should be measured beyond time savings and public benchmarks, using four dimensions: accuracy (work-ready), trust (honors DLP, labels and permissions), speed (median end-to-end time on equal settings) and cost (measured usage at list price, with Copilot credits per task via /cost).

Live demos evaluate Copilot Chat (included in the license), Copilot Cowork (usage-based) and Cost Management (admin view of spend by user and agent). The slides explain what drives credits: agent loops re-send growing context on every step, so more tool steps mean more usage, while cache rates (Cowork 96.7% in the demo, around 37% for short sessions) and model choice matter. Fewer, better-targeted queries reduce credits. A GigaOm and Microsoft TCO comparison (October 2026) is cited with the caveat that it consists of modeled estimates. An eval kit is offered for running your own evaluations.
