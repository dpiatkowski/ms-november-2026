# Security for systems that won’t obey

**Speaker(s):** Ben Hanson

## Summary

A field CISO argues agentic security conversations lack clarity and offers two anchors for thinking: "can versus should" and "point in time versus the chain." Industry controls (data access, token scope, API permissions, network paths, Zero Trust, microsegmentation) answer whether an agent can act, but agents have agency to plan, decide and adapt, so the harder question is whether an action still makes sense for the task.

An example cites an incident where a token found on a device was unlimited; narrow scoping might have slowed the agent, but the system never established that the command belonged to the task. The session argues for observing runtime behavior in context and reasoning across the whole chain of steps rather than judging each step alone.
