# Visual Studio governance for the agentic era

**Speaker(s):** Tina Schrepfer (LI), Praveen Sethuraman

## Summary

The session covers governance of Visual Studio for enterprise administrators across three areas. Deploy and maintain: create a full layout, use reusable team .vsconfig files, and keep an approved layout current, standardizing the process rather than each installation. Govern extensions: a Private Marketplace for VSIX extensions (partly available, partly in progress). Govern AI: protect IP, bound agent actions and govern consistently.

AI options include GitHub Copilot, bring your own key (Foundry, Anthropic, OpenAI, OpenRouter), organization-hosted OpenAI-compatible endpoints and local inference (Ollama, LM Studio). Guardrails can follow the Copilot account or be delivered per device, with controls such as disabling agent mode, disabling bypass permissions, restricting connections and approving models. The slides note that managed-settings support in Visual Studio is in development and that supported controls vary by client and build.
