# Agentic AI in action: Reimagining software engineering at scale

**Speaker(s):** Meagan Cojocar, Rupal Shah, Fraser Street

## Summary

Hewlett Packard Enterprise describes how its HPE Networking campus and branch switching team (about 1,000 engineers working in a 12-year-old monolithic repository for AOS-CX) built an AI Management System (AIMS) on GitHub Copilot. AIMS has six pillars: planning intelligence, engineering productivity, CI/test and secure release, triage, root-cause analysis and remediation, cloud management integration, and analytics.

Its evolution runs from individual Copilot use in VS Code (early 2025), to mirrored repositories with full indexing (late 2025), to specialized agents (early 2026) and a unified platform that orchestrates them (mid-2026). One control plane supports both engineer-driven requests and autonomous bot workflows, expanding toward an automated software-maintenance loop that includes AI code inspection for guideline violations and issues such as memory leaks. The session also covers GitHub Copilot for any code.
