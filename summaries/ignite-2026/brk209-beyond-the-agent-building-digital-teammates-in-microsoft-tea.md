# Beyond the Agent: Building Digital Teammates in Microsoft Teams

**Speaker(s):** Natalie Pienkowska, Umang Sehgal

## Summary

The session argues agents become teammates when they work in the flow of Teams, and is organised around three pillars: design, identity/security/access, and context. For builders it contrasts Copilot Studio (low code, no backend) with the Teams CLI and SDK (code first, with chats, channels, meetings, adaptive cards and proactive messaging).

On design, agents should behave like colleagues: reply in the thread, react to acknowledge, @mention, follow up when blocked, cite sources and show plans, with message formats from Markdown and Adaptive Cards to HTML widgets and canvas. A demo has GitHub Copilot find a root cause, file an issue and return a pull request in a channel thread.

On trust, the slides distinguish app-based agents (acting on behalf of a user) from agentic users (their own Entra ID identity, mailbox, calendar and @mentionability, with Conditional Access, least privilege, Purview audit and lifecycle controls). Agent 365 is shown as the place to see and govern agent fleets.
