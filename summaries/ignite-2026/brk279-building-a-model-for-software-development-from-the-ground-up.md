# Building a model for software development from the ground up

**Speaker(s):** Yanan Cai, Yang Liu, Faith Xu

## Summary

The session explains why and how Microsoft built its own coding models for GitHub Copilot, arguing the model and product should be designed as one system around real developer workflows. The MAI-Code line runs from MAI-Code-1-Flash (June) and 1.1-Flash (August, native vision, lower price) to MAI-Code-2 (flagship for enterprise everyday development) and MAI-Code-2-Flash (more cost-efficient) announced at Ignite.

Training covers pretraining plus post-training with SFT and reinforcement learning on hundreds of thousands of real-world instances, with rollouts run through real product harnesses (Copilot CLI and others) and rewards from running checks, illustrated with a Kiota Python SDK bug fix. Reasoning levels make performance-versus-token-cost trade-offs explicit, and the session also covers benchmarking, online experimentation in GitHub Copilot and what is next.
