# Build the agentic workplace with Dell and Microsoft

**Speaker(s):** Stefan Kinnestrand, Sahil Kumar, Marc Hammons, Jon Siegal

## Summary

Dell Technologies and Microsoft argue the PC matters more in the agentic workplace: the slides cite that running cloud-based agentic workloads concurrently can degrade PC performance by up to 24%, because foreground office work, background cloud agents and local AI all run at once, so benchmarks that measure only one layer miss the hidden cost.

Three takeaways: people and agents now share the PC, hybrid intelligence changes the economics of refresh decisions into a broader AI infrastructure decision, and Dell and Microsoft professional services can help. Dell's Pro line is shown for sustained AI performance, while Microsoft highlights agents contained and managed by IT, local models that cut cloud cost and keep data on the PC, and agents using local context and actions. Figures are vendor-reported.
