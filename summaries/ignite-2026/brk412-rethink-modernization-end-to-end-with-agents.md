# Rethink modernization end to end with agents

**Speaker(s):** Nish Anil, Ashish Babbar, Ankit Surkar, Shannon Gray

## Summary

The session covers rethinking modernization end to end with agents through Azure Catalyst. Customer outcomes listed include 450K+ lines of .NET code upgraded, a 100 TB data warehouse modernized (Aldermore), Del Monte migrating primary systems in three months, Procter and Gamble reporting 40% average performance gains for SAP workloads and Ahold Delhaize accelerating delivery up to 40%.

Lumen Technologies describes transforming a complex estate: establishing readiness, prioritizing applications by business value (mapping dependencies, sequencing by criticality and risk), using GitHub Copilot modernize to analyze code and compatibility, and modernizing a 20-year-old mission-critical Java application, with next steps toward a programmable network as "the trusted network for AI." Figures are customer-reported.
