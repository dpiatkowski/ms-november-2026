# AI runs on data. Is your storage architecture ready?

**Speaker(s):** Vamshi Kommineni, Saurabh Sensharma, Harish Arora

## Summary

The session explains Azure Storage as the common data substrate for AI training, fine-tuning, inference and agents (checkpoints, KV cache snapshots, agent state and audit logs), with portfolio coverage across block, object and file. For training it describes integration paths (direct infrastructure, managed via AKS AI Manager, fully managed via Foundry) and tools such as BlobFuse, fsspec, and the distributed accelerator for cloud storage (DACS).

Announced for Azure Managed Lustre: online expansion while jobs run, rebalance (preview) and an AMLFS Plus SKU with about 5x the bandwidth and namespace limits (up to 120 PiB and 2.5 TB/s, up from 25 PiB and 512 GB/s). Slides also cite MLPerf Storage v3.0 results. NVIDIA joins as a speaker, and AI-powered data management topics are covered.
