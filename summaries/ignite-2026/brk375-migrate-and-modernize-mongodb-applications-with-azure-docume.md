# Migrate and modernize MongoDB applications with Azure DocumentDB

**Speaker(s):** Abinav Rameesh, Hunter Bernhardt, Felipe Vega

## Summary

The session covers migrating and modernizing MongoDB applications with Azure DocumentDB, described as a fully managed, MongoDB-compatible service (MIT-licensed open source, native vector and full-text search). The slides claim at least 40% lower price than MongoDB Atlas and TCO reductions on average around 67%, with 2x transactions per dollar; these are vendor claims.

AB InBev describes migrating from MongoDB Atlas, balancing jobs across 562 varied clusters to minimize replication lag, selectively un-sharding collections, handling collections over 20 TB with checkpointed retries, using a VS Code migration extension, and keeping both systems running for at least four months. Abercrombie and Fitch describes moving its Digital Product Hub, which runs almost 900 daily jobs connecting internal data to external partners.
